# AI Analysis — Prompt & API Call Logic

Extracted from `stock-dashboard/src/app/api/ai-analysis/route.ts`. This covers only the
Claude request/response contract — no caching, scheduling, or frontend rendering.

## Inputs needed (data you must have before building the prompt)

Per ticker, from historical rows `{date, signal, price, strength, confidence, adx}`:

- `tickers` — list of all ticker symbols
- `consensus` — counts of BUY/SELL/HOLD across latest signals
- `signalChanges` — list of tickers whose signal changed vs. the previous trading day (`"TICK: PREV→NEW"`)
- `portLine` — one-line portfolio P&L string: equal-weight strategy % vs buy-and-hold %
- `snapshotLines` — one padded line per ticker: `ticker | signal | price | streak | period_return | confidence | adx | win_rate/expectancy`
- `fwdLine` — historical avg next-trading-day return per signal type: `BUY: +x% (n=..) | SELL: ... | HOLD: ...`
- `today` — ISO date string

## Exact prompt template

```
You are reviewing algorithmic stock signals generated by a systematic trading bot. Today is ${today}.

Portfolio: ${tickers.length} tickers | BUY: ${consensus.BUY} | SELL: ${consensus.SELL} | HOLD: ${consensus.HOLD}
${signalChanges.length ? `Signal changes since yesterday: ${signalChanges.join(", ")}` : "No signal changes since yesterday."}

Portfolio performance (equal-weight simulation):
${portLine}

Current snapshot (ticker | signal | price | streak | period_return | confidence% | ADX | win_rate/expectancy):
${snapshotLines}

Signal effectiveness — avg next-trading-day % return across all historical data:
${fwdLine}

Respond with ONLY this JSON object (no markdown fences, no text outside the JSON):
{
  "generatedAt": "${today}",
  "marketSummary": "2-3 sentences on the overall signal environment — reference the BUY/SELL/HOLD split, whether the strategy is beating buy-and-hold, and any notable signal changes today",
  "topPicks": [{"ticker": "TICK", "reason": "specific, data-backed reason in one sentence"}],
  "riskWatch": [{"ticker": "TICK", "reason": "specific, data-backed concern in one sentence"}],
  "portfolioNote": "1-2 sentences on portfolio health, strategy vs buy-and-hold, or actionable guidance"
}

Rules:
- topPicks: 1–3 tickers with the strongest BUY conviction (long BUY streak, high confidence, positive expectancy, strong ADX).
- riskWatch: 1–3 tickers on SELL signals, weak confidence, negative expectancy, or contradictions (BUY signal with negative expectancy, or SELL with positive expectancy — flag explicitly).
- Highlight tickers that just changed signal today as momentum shifts worth watching.
- Be specific: cite actual ticker names, streak lengths, confidence scores, or % figures.
- Do not invent data not present above.
```

## Formatting details for the two computed lines

**`snapshotLines`** — one line per ticker, fields padded and joined with `" | "`:

```
ticker.padEnd(5)
signal.padEnd(4)
`$${price.toFixed(2).padStart(8)}`
`streak=${streakSignal}×${streakDays}d`.padEnd(14)
`period=${sign}${periodChangePct.toFixed(1)}%`.padEnd(14)
`conf=${confidence.toFixed(0).padStart(3)}`
`adx=${adx.toFixed(0).padStart(3)}`
stats.totalTrades ? `wr=${round(winRate)}% exp=${sign}${expectancy.toFixed(1)}%` : "no_completed_trades"
```

**`fwdLine`**:

```
`BUY: ${sign}${fwd.BUY.avg.toFixed(3)}% (n=${fwd.BUY.count}) | SELL: ${sign}${fwd.SELL.avg.toFixed(3)}% (n=${fwd.SELL.count}) | HOLD: ${sign}${fwd.HOLD.avg.toFixed(3)}% (n=${fwd.HOLD.count})`
```

`sign` = `"+"` if value ≥ 0, else `""`.

## API call

```ts
const client  = new Anthropic();
const message = await client.messages.create({
  model: "claude-opus-4-8",
  max_tokens: 4096,
  thinking: { type: "adaptive" },
  messages: [{ role: "user", content: prompt }],
});
```

SDK: `@anthropic-ai/sdk@^0.104.1`

## Response parsing

```ts
const textBlock = message.content.find(b => b.type === "text");
const jsonMatch = textBlock.text.match(/\{[\s\S]*\}/);
const analysis  = JSON.parse(jsonMatch[0]);
```

Expected shape:

```ts
{
  generatedAt: string;
  marketSummary: string;
  topPicks: { ticker: string; reason: string }[];
  riskWatch: { ticker: string; reason: string }[];
  portfolioNote: string;
}
```
